## 💡 About SHORTEE

**SHORTEE** is a web-based URL shortening platform designed to transform long URLs into simple, shareable links while giving users tools to manage and analyse their links.

The application combines **user authentication, URL shortening, URL management, analytics and backend API functionality** into a single web application.

The project was built as a practical software engineering project to apply concepts in **backend development, database integration, API development, authentication and web application architecture**.

### 🎯 The Problem

Long URLs can be difficult to share, remember and manage.

SHORTEE provides a simpler way to:

* 🔗 Create short, shareable URLs
* 👤 Manage links through user accounts
* 📊 Monitor link activity
* ✏️ Create customised aliases
* 🔍 Expand shortened URLs
* 🗑️ Delete unwanted links
